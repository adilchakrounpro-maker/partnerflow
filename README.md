# PartnerFlow

Plateforme de recommandation avec QR codes, équipes et commissions.

## Site en ligne

https://my-partnerflow.netlify.app

## Repo

https://github.com/adilchakrounpro-maker/partnerflow

## Contenu

Ajoute le fichier `index.html` à la racine du repo, puis relie ce repo à Netlify pour déployer automatiquement à chaque push.

### Fonctionnalités

- Comptes particuliers & entreprise
- QR questionnaire (multi-catégories)
- QR recrutement d'équipe
- Dashboard, leads, profil
- Section Équipe pour les entreprises
